# RM 模拟器 · 游戏规则

游戏里有三个模式：**训练场**（练车）、**RMUC2023**、**RMUC2024**。本文按这三个模式分别说明规则。

所有数值都取自模拟器实际跑出来的行为，不是官方手册的复述；两者不一致的地方集中在[文末](#附录与官方手册的差异)。

---

## 一、三个模式共有

### 赛制

- 一场 **420 秒**。
- **场上车辆全部就绪就自动开始**，没有准备倒计时。
- 只有两种结束方式：**一方基地被击毁**，或**时间耗尽**。没有加时，也没有平局。
- 分出胜负的唯一途径是打掉基地；时间到了不比较任何分数。

### 车辆编号

小地图与裁判系统里的编号固定如下（红方 / 蓝方）：

| 单位 | 红 | 蓝 |
|---|---|---|
| 英雄 | 1 | 21 |
| 工程 | 2 | 22 |
| 步兵 | 3、4、5 | 23、24、25 |
| 空中 | 6 | 26 |
| 哨兵 | 7 | 27 |
| 雷达 | 9 | 29 |
| 前哨站 | 18 | 38 |
| 基地 | 19 | 39 |

### 弹丸与伤害

- **17mm 命中 10 点，42mm 命中 100 点，碰撞 2 点。**
- **打在任何部位伤害都一样**，没有装甲部位减伤，也不随车辆等级变化。
- 攻击方带攻击增益时按比例增伤；受击方带防御增益时按比例减伤。**打建筑不吃减伤。**
- **打到自己人照样掉血**，只是不结算经验。
- 命中只看接触，**没有最低初速度要求**，擦到就算。

### 热量

- 每发出一发 **17mm 增加 10 点热量，42mm 增加 100 点**。
- 热量随时间冷却，冷却快慢由所选的枪口模式决定。
- **超热扣血**：热量每超出上限 250 点，扣掉一成上限血量；一旦超过上限的两倍，超出部分每 250 点直接扣掉一整条血，同时把热量压回两倍上限。
- 剩余热量不够一发时打不出去。

### 功率

- 底盘功率超出上限时，先消耗缓冲能量，再消耗车载能量（1900），两者都空了才开始扣血。
- 扣血按超出比例：**超出不到一成扣一成血，不到两成扣两成，超过两成扣四成**（每 0.1 秒结算一次）。
- 功率有余量时会回充缓冲和能量。
- **工程车不限功率。**

### 死亡与复活

- 阵亡后读条：**10 秒起步，比赛每过去 10 秒多等 1 秒** —— 开局阵亡等 52 秒，最后一分钟阵亡只等 10 秒。
- 可以花金币**立即复活**；每买活一次，读条再延长 20 秒。
- **免费复活只回一成血；花钱买活回满血并解锁发射机构。**
- 复活**原地起身**，不换位置；复活后有短暂无敌。
- **哨兵、基地、前哨站不会复活。**

### 操作

W/A/S/D 控制底盘，鼠标控制云台，左键射击，按 P 打开车辆面板并显示鼠标。

## 二、训练场

**定位：练车场。** 车辆数值用 RMUC2024 的完整十级表，但场上**没有基地、前哨站和兑换站，也不计算经验** —— 所以这里**不判胜负、没有金币、不会升级**。

**赛制**

- 420 秒，所有车就绪即自动开始，时间到就结束。
- 每方七台车：英雄、工程、三名步兵、哨兵，另有增益点可以踩。

**车辆开局状态**

| 车型 | 血量 | 功率上限 |
|---|---|---|
| 英雄 · 血量优先 | 250 | 55 |
| 英雄 · 功率优先 | 200 | 70 |
| 步兵 · 血量优先 | 200 | 45 |
| 步兵 · 功率优先 | 150 | 60 |
| 工程 | 250 | 不限 |
| 哨兵 | 400 | 100 |

- 哨兵开局带 **700 发** 17mm 弹。
- 工程车没有发射机构，不能射击。
- 虽然有十级成长表，但没有经验来源，实战中不会升级。

**进入方式**：在原选角界面选好车，点击 Spawn。没 Spawn 之前不启用第一人称操作。按 P 可以在场上已有的车之间切换操控，**不会生成新车**。

**小地图**：编号、朝向和血量来自场上真实的裁判实体，编号与 RMUC 一致。

## 三、RMUC2023

### 赛制与胜负

- 420 秒，车辆全部就绪即自动开始。基地被击毁或时间耗尽结束，没有加时和平局。
- **基地 5000 血 + 250 点护盾，开局无敌；前哨站 1500 血。**
- **前哨站开赛满三分钟后停转。**
- 开赛三分钟内打掉前哨站 500 血，最后攻击它的人得 **25 点经验**（每局一次）。

### 击毁顺序（决定基地能不能打）

1. 己方**前哨站被毁** → 己方哨兵与基地**解除无敌**。
2. 己方**哨兵也被毁** → 己方**基地护盾清零**（250 点护盾没了）。
3. 基地被毁 → **判负**。

### 控制点

占领控制点满 **6 秒**，可以**压制对方前哨站**，让它转速减半。双方都不占或都占时压制解除，可以反复争夺。

### 经济

- 开局每方 **400 金币**；剩 6、5、4、3、2 分钟时各发 **50**，剩 1 分钟时发 **150**。
- 全场第一块**金矿**兑换时额外多给 **250** 金币。
- **击毁敌方机器人不给金币。**
- 弹药按发买：**17mm 每发 1 金币，42mm 每发 15 金币**。本方 17mm 库存 1500 发、42mm 库存 100 发，买完为止。
- 远程补给（下单 6 秒后生效，下单前需 6 秒内未受伤也未开火，**每种限用两次**）：
  - 回血 **100 金币**，每过一分钟涨 20，回六成血
  - 17mm **200 金币**，加 100 发
  - 42mm **300 金币**，加 10 发
- 兑换站（只有控制方的工程师能兑换）：银矿 75 起、金矿 100 起，换得越多单价越高，累计兑换额跨过门槛后单价升到 **1.3 倍**。
- 兑换前等得越久越亏：**15 秒内不亏，等满 50 秒以上矿石就换不到钱了。**

### 车辆与成长

车辆只有**三级**成长。

| 车型 · 模式 | 血量（1→3 级） | 功率（1→3 级） |
|---|---|---|
| 英雄 · 血量优先 | 250 / 350 / 450 | 55 / 60 / 65 |
| 英雄 · 功率优先 | 200 / 250 / 300 | 70 / 90 / 120 |
| 步兵 · 平衡型 | 300 / 400 / 500 | 60 / 80 / 100 |
| 步兵 · 血量优先 | 200 / 300 / 400 | 45 / 50 / 55 |
| 步兵 · 功率优先 | 150 / 200 / 250 | 60 / 80 / 100 |
| 工程 | 250 | 不限 |
| 哨兵 | 1000 | 150 |

- 经验除了打人还会**随时间自动增长**：英雄每秒 6 点，步兵每秒 3 点。
- 升级门槛：英雄 60 / 140，步兵 30 / 90。
- 升级同时提升血量上限、功率上限和枪口热量上限，并**立刻补满新增的血量**。
- 击毁敌方机器人时，击杀者得到对方的经验值，**首杀额外 +50**；参与助攻的人各得四分之一。

### 复活

- 读条与通用规则相同（10 秒起步，每过去 10 秒多等 1 秒）。
- 买活价格 = **已开赛分钟数 × 100 +（车辆等级 + 1）× 50** 金币。
- 免费复活回一成血，买活回满血并解锁发射机构。

### 场地

- **矿区**：工程师占领后出矿，每次一块，矿石拿去兑换站换金币。
- **狙击点**：英雄获得狙击增益，增益期间每开一炮额外得 **10 金币**。
- **增益点**：踩上可拿增益。

### 注意

- **兑换累计额升到最高档时收益会掉到零**，不要用最高档兑换。

## 四、RMUC2024

### 赛制与胜负

- 420 秒，车辆全部就绪即自动开始。基地被击毁或时间耗尽结束，没有加时和平局。
- **基地 5000 血 + 250 点护盾，开局无敌；前哨站 1500 血。**
- **哨兵 400 血，开局就是满级，并带 400 发弹。**
- 前哨站开赛满三分钟后停转。
- 开赛三分钟内打掉前哨站 500 血，最后攻击它的人得 **100 点经验**（每局一次）。

### 击毁顺序（与 2023 的关键差别）

1. 己方**前哨站被毁** → 己方哨兵**解除无敌并补回 600 血**（2023 是解锁哨兵和基地的无敌，不给补血）。
2. 己方**哨兵也被毁** → 己方**基地护盾清零**。
3. 基地被毁 → **判负**。

建筑不吃减伤；打到自己人照样掉血，只是不给经验。

### 经济

- 开局每方 **400 金币**；剩 6、5、4、3、2 分钟时各发 **50**，剩 1 分钟时发 **150**。
- 第一块**金矿**兑换额外多给 **250** 金币。
- 英雄带狙击增益时，每开一炮额外得 **10 金币**。
- **击毁敌方机器人不给金币。**
- 弹药按发买：**17mm 每发 1 金币，42mm 每发 15 金币**。
- 远程补给（下单 6 秒后生效，下单前需 6 秒内未受伤也未开火，**次数不限**）：
  - 回血 **50 金币**，每过一分钟涨 20，回六成血
  - 17mm **150 金币**，加 100 发
  - 42mm **200 金币**，加 10 发
- 兑换站：银矿 75 起、金矿 200 起；累计兑换额越高单价越高，**最高翻到两倍**。
- 兑换前等得越久越亏：15 秒内不亏，超过 50 秒矿石就换不到钱了。

### 车辆与成长

车辆有**十级**成长。

| 车型 · 模式 | 血量（1→10 级） | 功率（1→10 级） |
|---|---|---|
| 英雄 · 血量优先 | 250 / 275 / 300 / 325 / 350 / 375 / 400 / 425 / 450 / 500 | 55 / 60 / 65 / 70 / 75 / 80 / 85 / 90 / 100 / 120 |
| 英雄 · 功率优先 | 200 / 225 / 250 / 275 / 300 / 325 / 350 / 375 / 400 / 500 | 70 / 75 / 80 / 85 / 90 / 95 / 100 / 105 / 110 / 120 |
| 步兵 · 血量优先 | 200 / 225 / 250 / 275 / 300 / 325 / 350 / 375 / 400 / 400 | 45 / 50 / 55 / 60 / 65 / 70 / 75 / 80 / 90 / 100 |
| 步兵 · 功率优先 | 150 / 175 / 200 / 225 / 250 / 275 / 300 / 325 / 350 / 400 | 60 / 65 / 70 / 75 / 80 / 85 / 90 / 95 / 100 / 100 |
| 工程 | 250 | 不限 |
| 哨兵 | 400 | 100 |

- 升一级要 **550 点经验**（最后一级 600）。**没有随时间自动增长的经验**，只能靠打。
- 经验来源：
  - 开炮：17mm 每发 1 点，42mm 每发 10 点
  - 造成伤害：按伤害的 **4 倍**计；打建筑只有 **1 倍**
  - 击毁敌方机器人：**对方等级越高给得越多**，参与助攻也有份
  - 首次踩上**能量机关点**：**300 点**
- **小增益期间全队经验翻倍**，双倍部分上限 800 点。
- 平衡型车辆经验 **1.5 倍**。
- 升级同时提升血量上限、功率上限和枪口热量上限，并立刻补满新增的血量。

### 复活

- 读条与通用规则相同。
- 买活价格 = **已开赛分钟数 × 80 +（车辆等级 + 1）× 20** 金币，比 2023 便宜。
- 免费复活回一成血，买活回满血并解锁发射机构。

### 场地与增益

- 场上有 **3 处矿区、6 处高地、2 处基地增益区、2 处能量机关点**，另有**回血补给区**。
- **回血区每秒回复一成血量**，进区同时解锁发射机构。
- 增益区会随时间**定时升档**：比赛剩三分钟、四分钟、五分钟时各升一次，越往后增益越强。
- **大增益**按能量机关的命中得分给攻击加成，最高**四倍攻击**，持续 45 秒：

| 机关得分 | 攻击加成 |
|---|---|
| 15 分及以下 | 50% |
| 16 – 25 | 55% |
| 26 – 35 | 60% |
| 36 – 40 | 100% |
| 41 – 45 | 200% |
| 46 | 240% |
| 47 | 280% |
| 48 | 320% |
| 49 | 360% |
| 50 | **400%** |

- 能量机关要先占领己方的**激活区**才能启动。
- **雷达标记**：只有雷达车能标记敌方，命中越准进度涨得越快；标记成功后目标**防御下降**。

## 五、三个模式差异速查

| 项目 | 训练场 | RMUC2023 | RMUC2024 |
|---|---|---|---|
| 时长 | 420 秒 | 420 秒 | 420 秒 |
| 判胜负 | **不判** | 基地被毁 / 时间到 | 基地被毁 / 时间到 |
| 基地、前哨站 | **没有** | 有 | 有 |
| 金币、兑换 | **没有** | 有 | 有 |
| 成长级数 | 10 级表（**无经验来源**） | 3 级 | 10 级 |
| 时间自动经验 | 无 | 英雄 6/秒、步兵 3/秒 | 无 |
| 哨兵开局 | 700 发弹 | 1000 血 | 满级 + 400 发弹 |
| 前哨站被毁的后果 | — | 哨兵与基地解除无敌 | 哨兵解除无敌**并补 600 血** |
| 买活价格 | — | 分钟数×100 +（等级+1）×50 | 分钟数×80 +（等级+1）×20 |
| 远程补给次数 | 各 2 次 | 各 2 次 | **不限次** |
| 远程补给价格 | — | 回血 100 / 17mm 200 / 42mm 300 | 回血 50 / 17mm 150 / 42mm 200 |
| 特殊机制 | 练车 | 控制点压制前哨站 | 能量机关、高地、雷达标记 |

## 六、性能模式怎么选

选车时能选的底盘和枪口模式，两个赛季的**顺序是反的，别记混**。

| 部位 | RMUC2023 | RMUC2024 |
|---|---|---|
| 英雄底盘 | 1 血量优先，2 功率优先 | 1 血量优先，2 功率优先 |
| 步兵底盘 | 1 平衡型，2 血量优先，3 功率优先 | 1 血量优先，2 功率优先 |
| 17mm 枪口 | 1 爆发型，2 冷却型，3 射速型 | **1 冷却型，2 爆发型** |
| 42mm 枪口 | 1 爆发型，2 射速型 | 只有 1 种 |
| 工程 / 哨兵 | 各 1 种 | 各 1 种 |

枪口模式决定热量上限、冷却速度和初速度。爆发型热量上限高、冷却慢；冷却型反之；射速型初速最高。

## 七、需要注意的实装细节

这些是模拟器当前的真实行为，和直觉或官方手册可能不同：

1. **每局开局 42mm 库存实际是 1500 发**（本应是 100 发），够用到比赛结束。
2. **RMUC2023 兑换累计到最高档时收益为 0**，不要用最高档兑换。
3. **命中没有最低初速度要求**，擦到就算，不存在"初速不够打不掉血"。
4. **42mm 是固定 100 伤害**，不按初速度百分比扣血。
5. **飞镖没有实装**，打出去不造成伤害。
6. **没有违规判罚**，不存在罚分或警告扣血。
7. **没有加时和拼点**，时间到就直接结束。
8. 补给区**没有**"脱战 6 秒后回血提速"这回事，回血速度固定。

## 附录：与官方手册的差异

正文按模拟器实装写。以下是核查过的差异，**仅供参考，游戏内以实装为准**。

**一致的部分**（说明模拟器是照手册实现的）：比赛时长 420 秒、每发热量 17mm +10 / 42mm +100、超热扣血公式、复活读条公式、定时金币（每分钟 +50、终盘 +150）、前哨站 1500 血与基地 5000 血、哨兵热量上限 400 与冷却 80、复活后的 10 秒无敌。

**不一致的部分**：

| 项目 | 模拟器实装 | 官方手册 |
|---|---|---|
| 42mm 伤害 | 固定 100 | 按初速度查表扣上限血量的百分比 |
| 复活回血 | 上限血的一成 | 部分版本为两成 |
| 飞镖 | 未实装 | 对基地 / 前哨站造成上限血量的五分之一 |
| 基地护甲展开 | 未实装 | 基地血量降到 2000 以下时护甲展开 |
| 补给区回血提速 | 未实装 | 连续 6 秒未受伤未开火后提速到 25% |
| 平局 / 加时 | 无 | 有判定 |
| 违规判罚 | 无 | 有罚分、扣血 |

来源：大疆官方发布的 RMUC 2024 规则手册对比版、RMUC 2024 规则及制作规范修订说明 V1.0、RMUC 2025 规则手册 V1.2.0。
